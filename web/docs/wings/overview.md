# Wings

Wings — это агент на узле, работающий на хостах ваших игровых серверов. Он управляет Docker-контейнерами от имени панели, получает инструкции через API Wings и сообщает обновления статуса обратно. Каждый экземпляр Wings может управлять несколькими игровыми серверами, а одна панель может подключаться к нескольким экземплярам Wings.

## Минимальные требования

- **Операционная система**: Ubuntu 22.04 LTS или новее, Debian 11 или новее, либо любой дистрибутив Linux, поддерживающий современные версии Docker
- **Архитектура CPU**: x86_64, ARM64, RISC-V или PPC64LE
- **ОЗУ**: минимум 512 МБ (рекомендуется 1 ГБ или больше)
- **Дисковое пространство**: минимум 256 МБ

::: warning Требуется Docker
Wings использует Docker для запуска и изоляции контейнеров игровых серверов. Docker должен быть установлен и запущен на хосте. Минимальные требования выше не включают ресурсы, необходимые самим игровым серверам, — они дополнительные.
:::

## Технический обзор

- **Язык**: :crab: Rust
- **Управление контейнерами**: Docker/Podman через [`bollard`](https://crates.io/crates/bollard)
- **Веб-фреймворк**: [`axum`](https://crates.io/crates/axum)
- **Среда выполнения**: [`tokio`](https://crates.io/crates/tokio)
- **Обработка SSH**: [`russh`](https://crates.io/crates/russh)

Официально поддерживаются только Linux и macOS из-за зависимости от Unix-специфичных возможностей. Большая часть функционала реализована с нуля или через небольшие специализированные крейты, чтобы дерево зависимостей оставалось лёгким.

## Тома

Wings использует несколько каталогов на хосте. Знание, где находится каждый, важно для устранения неполадок, резервного копирования и управления диском.

Большинство из них по умолчанию находится под `root_directory` (см. [плейсхолдеры путей](configuration.md#конфигурация-системы)), поэтому пути ниже показаны уже разрешёнными.

| Том | Описание | Пути по умолчанию |
| :--- | :--- | :--- |
| `root_directory` | Постоянное состояние Wings (состояние сервера для восстановления после перезапуска) | **Unix:** `/var/lib/calagopus-wings`<br>**Win:** `C:\\ProgramData\\Calagopus-Wings` |
| `log_directory` | Файлы логов Wings | **Unix:** `/var/log/calagopus-wings`<br>**Win:** `C:\\ProgramData\\Calagopus-Wings\\logs` |
