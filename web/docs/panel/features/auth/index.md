# Аутентификация

Всё, что можно сделать без сессии, находится под `/auth/`. Эти страницы имеют один макет с центрированной карточкой: иконка и название панели (или настроенный баннер) сверху, заголовок и подзаголовок, а также форма. Под формой — разделитель **ИЛИ** с альтернативными действиями, отображаемый на каждой странице, кроме финальной формы [выбора нового пароля](./password-reset.md#выбор-нового-пароля).

Если настроенный URL приложения панели не совпадает с адресом в браузере, на страницах [Вход](./login.md), [Регистрация](./register.md), [запроса сброса пароля](./password-reset.md#запрос-сброса) и [проверки двухфакторной аутентификации](./login.md#проверка-двухфакторной-аутентификации) над карточкой отображается предупреждающий баннер. Он не отображается на форме [выбора нового пароля](./password-reset.md#выбор-нового-пароля) или на странице [входа через OAuth](./login.md#вход-через-oauth).

| Страница | Описание |
| --- | --- |
| [Вход](./login.md) | Двухэтапный процесс входа, passkeys, провайдеры OAuth и проверка двухфакторной аутентификации |
| [Регистрация](./register.md) | Создание аккаунта, когда регистрация включена |
| [Сброс пароля](./password-reset.md) | Запрос письма для сброса и выбор нового пароля |

## Что контролируют администраторы

Что именно отображается на этих страницах, зависит от настроек панели:

| Поведение | Где |
| --- | --- |
| Включена или выключена регистрация | **Включить регистрацию** в [Настройки > Приложение](../admin/settings.md#приложение) |
| Кто обязан использовать 2FA | **Требование двухфакторной аутентификации** в [Настройки > Приложение](../admin/settings.md#приложение) |
| Какие факторы засчитываются в это требование | **Принятые методы двухфакторной аутентификации** в [Настройки > Приложение](../admin/settings.md#приложение) |
| Коды по email как второй фактор | **Email-двухфакторная аутентификация** в [Настройки > Приложение](../admin/settings.md#приложение) |
| Должны ли новые аккаунты подтверждать email | **Требовать подтверждения email** в [Настройки > Приложение](../admin/settings.md#приложение) |
| Captcha на формах аутентификации | [Настройки > Captcha](../admin/settings.md#captcha) |
| Passkeys и безлогинный вход | [Настройки > Webauthn](../admin/settings.md#webauthn) |
| Кнопки входа через OAuth | [OAuth-провайдеры](../admin/oauth-providers.md) |
| Сброс и другая исходящая почта | [Настройки > Почта](../admin/settings.md#почта) |
| Ограничения частоты запросов на эндпоинтах аутентификации | [Настройки > Лимиты запросов](../admin/settings.md#лимиты-запросов); у callback OAuth фиксированный лимит — 6 попыток за 5 минут |
